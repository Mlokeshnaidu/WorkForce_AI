# WorkForce AI Pro - Frontend Client

This directory contains the React SPA frontend client for the WorkForce AI Pro platform, built using Vite, Tailwind CSS, Recharts, and Axios.

## Development Setup

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Production build bundle
npm run build
```

The frontend application connects to the FastAPI backend API running on `http://localhost:8000`.

For full project architecture, system flow diagrams, and module documentation, please refer to the main repository [README.md](../README.md).
